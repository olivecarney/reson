# Reson v0.3 Implementation Plan

Execution: native in this session, no subagents; the supplied milestone brief is the spec. User explicitly requests direct implementation and authorizes merge only after all gates pass.

Goal: persistent ordered playlists, stable playback sequences and an independent explicit queue in the existing offline player.
Architecture: schema v2 on the single Rust library worker; existing caller-owned JSON ABI; Swift presentation and playback coordination; native AppKit tables and drag/drop. Existing generation-fenced Ended state supplies EOF, with regression tests before changes.

## Constraints
- Preserve tracks, folders, stable IDs and artwork maintenance; no dependencies or network runtime activity.
- Separate entry IDs from track IDs. Missing and unindexed M3U8 entries retain paths and titles; explicit folder import makes them available.
- Playback captures visible order, independent of selection and later edits. Explicit queue has priority and resumes sequence cursor. Previous traverses recorded attempts; no seek/repeat/shuffle.
- Preserve unrelated work; synthetic fixtures only. No merge with incomplete verification.

## Tasks
1. Storage/worker: write failing Rust tests for v1 migration, CRUD, duplicates, atomic insertion/removal/multi-row moves, missing/restored/stale references, worker shutdown. Implement `playlists`, `playlist_entries`, `playlist_create/rename/delete/add/remove/move` worker operations, paged entry queries and revision fences. Run workspace tests and commit.
2. M3U8: failing relative/Unicode/duplicate/missing/URI/UTF-8/newline/round-trip tests. Bounded parsing and atomic import/export on worker, no folder scan. Run tests and commit.
3. Playback: failing Swift sequence/queue/previous/completion tests and Rust EOF/Stop/failure/replacement tests. Implement a small value-type PlaybackSession, generation and acknowledgement fences in PlayerModel, bounded missing/invalid progression. Run suites and commit.
4. Native interface: tests for duplicate row selection, multi-row drop/move and bridge-backed editing. Add sidebar CRUD/drop targets, table context menus/drop delegates, queue table, transport and shortcuts. Build and Swift test; commit.
5. Verification: isolated native journey/restart/integrity, v0.2.2 comparisons at 270/5000/25000, final mandatory commands, complete diff review. Write docs/playlists-v0.3.md and docs/validation-v0.3.md with actual evidence; commit.
6. Integration: if every gate passes, fetch, push feature branch, merge preserving history, post-merge checks, push and verify remote main; preserve feature branch, no release/tag.

## Review focus
Stale playback completions after Stop/replacement; failed writes preserving original order; duplicate entry identity after edits; malformed/ambiguous local paths; shutdown during queued mutations. Each belongs to the tests of its owning task.
