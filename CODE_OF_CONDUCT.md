# Community code of conduct

We want reson to be welcoming to people of every background and experience level. Be considerate, respect differing perspectives, and give constructive feedback about the work. Assume good intent and accept corrections gracefully.

Harassment, discriminatory language, threats, unwanted sexual attention, doxxing and personal attacks are not acceptable in project spaces. Do not post anyone's private information without permission.

Maintainers may edit or remove inappropriate content and temporarily or permanently restrict participation. They will consider context, explain decisions where appropriate, and apply these expectations consistently. Maintainers are held to the same standards.

To report a concern privately, use the maintainer contact linked on [@olivecarney's GitHub profile](https://github.com/olivecarney). If a private channel is unavailable, open an issue asking for a confidential contact without including sensitive details. Do not publish a report containing private information.
