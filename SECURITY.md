# Security policy

Reson is an early-stage local desktop app. Security fixes target the latest release and `main`; older releases do not receive separate backports.

Please report vulnerabilities using [GitHub private vulnerability reporting](https://github.com/olivecarney/reson/security/advisories/new). Include affected versions, reproduction steps, impact and a small synthetic example when possible. Do not attach personal music, private library databases or credentials. If private reporting is unavailable, use the maintainer contact on [@olivecarney's profile](https://github.com/olivecarney) or request a confidential contact without disclosing the vulnerability publicly.

We will investigate reports and coordinate fixes and disclosure. There is no guaranteed response time or bug bounty.
